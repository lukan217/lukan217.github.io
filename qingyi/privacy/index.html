轻译 · 隐私与数据说明

适用版本：0.10.0　更新日期：2026-11-26

轻译是一款浏览器扩展，把你指定的网页文字发到你自己配置的模型 API；只有浏览器支持端侧翻译、目标语言对受支持且模型已预先下载时，才改为本机处理。本机实测 Chromium 158 的 en→zh-CN 返回 downloadable，扩展异步创建翻译器会失败；Edge 158 不支持该语言对。没有开发者中转服务器、账号、广告或统计埋点，也没有远程代码。

我们发送什么，发给谁

  • 正文段落、目标语言、你设置的术语和翻译指令会组成请求，发往你在设置里填写的 API 地址；请求头里带你自己填写的 API Key。Key 只发给你自己填写的地址。
  • 默认服务商是 DeepSeek 官方接口（https://api.deepseek.com/v1），默认模型 deepseek-flash；也可以选通义千问·百炼、硅基流动、Coarena 免费模型或自定义 OpenAI 兼容接口。接口地址必须是 HTTPS，仅本机地址允许 HTTP。
  • 启用上下文辅助时，会附带有限的页面标题和附近标题。不发送整页 HTML：扫描会跳过输入框、文本域、下拉框、按钮、独立代码块、表单、可编辑区域和隐藏内容；正文优先模式还会跳过导航、页脚和侧栏。行内代码与公式可能随段落一起发送。
  • 你主动开启的站点自动翻译，会在你访问该站点时发送请求。
  • YouTube 字幕轨道从视频站点获取，字幕文本走同一翻译通道。输入框翻译只在你主动触发时读取当前非敏感输入框、文本域或可编辑区里的文字。选中文字后会走单条词典式翻译。
  • 端侧翻译使用浏览器的 Translator API；只有模型已预先下载且浏览器允许创建翻译器时才在本机完成，文本和 Key 都不发往 API。语言判断只取有限正文样本，不调用模型也不上传。

用量只累加接口实际报告的 token 数，保存在本机会话里，不上传给开发者。请求从你的浏览器直接发往你填写的接口地址，开发者不经手、也不保存请求内容和 Key，因此无法代为查询、导出或删除服务商侧的记录；第三方如何处理这些数据，请查阅该服务商的隐私政策与数据留存条款。

API Key 保存在哪里

方式保存位置新设备使用
仅在本机保存（默认）Key 存在本机会话存储；勾选记住时另存本机扩展存储在另一台电脑重新填入
随浏览器账号同步Key 以扩展可读取的形式写入浏览器同步配置，没有额外口令加密同一账号的同步配置到达后可用；网站权限仍需每台设备各自允许
口令加密同步Key 经 AES-256-GCM 加密后进入同步配置；密钥由 PBKDF2-SHA-256、310000 次迭代派生首次输入口令解锁；口令不写进保存的配置

所有扩展存储区只对扩展自身开放，网页脚本读不到。Key 与 API 地址绑定，更换地址时需要重新填写。锁定或清除本机 Key 会删除本机和会话中的 Key。Key 不写入日志或截图，错误提示是固定文案、不回显 Key；浏览器开发者工具的网络面板按浏览器自身机制显示你发出的请求，那不是扩展写的日志。

本机保存的数据

  • 设置与阅读偏好保存在浏览器同步配置中。
  • 译文缓存使用 IndexedDB，最多 2000 条、30 天失效；缓存键是原文、目标语言、部分配置和上下文的摘要。缓存不跨设备同步，也不包含在备份中，可在设置里清除。
  • 生词本使用 IndexedDB，保存单词、音标、译文、释义、上下文、来源网址和收藏时间；导出的 CSV 同样含来源网址和收藏时间。
  • 会话数据保存在本机会话存储：任务状态、当前页偏好、已授权来源、临时自动翻译网站和用量。
  • 悬浮球的位置、折叠和「本站不显示」状态，以及最近用过悬停翻译的网站都保存在本机；单个网站的悬停翻译偏好随阅读偏好同步。

同步与备份

普通备份只包含设置，不含明文 API Key；加密备份包含加密后的配置，不包含口令。浏览器同步的传输和到达时间由浏览器处理，扩展没有自己的同步服务器。如需撤销 Key，请在模型服务商后台吊销或轮换；设置页的「锁定此设备」可清掉本机与本次会话里的 Key，同步副本可改回「仅在本机保存」或卸载扩展后清除。卸载或清除本机数据只删除本机的设置、译文缓存、生词本和 Key：已同步到浏览器账号的配置由浏览器管理，已发往模型服务商的记录需向服务商申请删除。
